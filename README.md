# B站课程列表导出工具

双击即可把 B站视频合集 / 多分P 视频的课程标题导出成 CSV，方便导入 Notion、Excel 或飞书多维表格做学习进度跟踪。
! 此项目由AI生成 ！

---

## 能做什么

- 给一个 B站视频链接，自动提取 BV 号
- 自动展开视频里的所有分 P
- 输出「序号 + 课程名称」两列 CSV
- 自动去掉重复的视频标题前缀
- 自动去掉 `_高清`、`高清720P`、`_超清` 等后缀

---

## 快速开始

### 1. 双击运行

直接双击 `bili_season_to_csv.py`，按提示操作：

```
==================================================
  B站课程列表导出工具
==================================================

请选择输入方式：
  [1] 粘贴 B站视频链接（自动提取 BV 号，单视频分 P 自动展开）
  [2] 输入一个或多个 BV 号（空格分隔）
  [3] 从 txt 文件读取 BV 号
  [0] 退出
```

一般选 **1**，粘贴链接，回车即可。

### 2. 输出文件

默认在同文件夹下生成 `bili_season.csv`。

运行到最后会提示：

```
输出文件名（直接回车使用默认 bili_season.csv）:
```

- 直接回车：用默认文件名
- 输入 `xxx.csv`：保存为 `xxx.csv`
- 输入完整路径：如 `D:\桌面\课程.csv`，保存到桌面

## 命令行用法

如果你更习惯命令行：

```bash
# 方式一：直接给链接
python bili_season_to_csv.py "https://www.bilibili.com/video/BV1dr4y1n7vA"

# 方式二：给一个或多个 BV 号
python bili_season_to_csv.py BV1dr4y1n7vA BV1GJ411x7h7

# 方式三：从 txt 文件读取（每行一个 BV 号或链接）
python bili_season_to_csv.py bvlist.txt

# 指定输出文件名
python bili_season_to_csv.py BV1dr4y1n7vA -o 我的课程.csv
```

## 导入 Notion 注意事项

CSV 导入 Notion 时，**不要**走「设置 → 导入 → CSV」，那会导致属性类型全丢。

正确做法：

1. 先在 Notion 里建好数据库，设置好属性类型
2. 进入数据库 → 右上角 `···` → `合并 CSV`
3. 选择生成的 CSV 文件
4. 确保 CSV 表头和 Notion 属性名**完全一致**（包括大小写）

建议先用 `notion_course_template.csv` 建库，再合并实际数据。

## 常见问题

### Q1：双击后闪退

`bili_season_to_csv.py` 已经加了暂停提示，跑完会显示「按回车键退出...」。

如果仍然闪退，可能是系统没有关联 Python 解释器，建议用命令行运行，或右键选择「打开方式 → Python」。

### Q2：程序提示抓取失败

可能原因：

- BV 号或链接复制错了
- 网络问题
- B站接口临时风控

可改用 `bili_season_export.js`：打开合集页 → F12 → Console → 粘贴脚本 → 回车，即可从页面直接抓取。

### Q3：课程名称里还有不想保留的内容

程序已经会自动清洗：

- 视频总标题重复前缀
- `_高清` / `_高清720P` / `_超清` / `720P` / `1080P` / `4K` 等后缀

如果还有特殊后缀想去掉，可以编辑 `bili_season_to_csv.py` 里的 `clean_suffix()` 函数，按同样格式添加规则。
